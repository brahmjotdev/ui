# Rival library review

## When

Only after **all parts Completed** (component Completed), or ad-hoc if the user asks. Not per chunk.

## Instructions

1. Read `references/library_principles.md` — cite principles with confidence; **never fabricate quotes**.
2. Score the coded API on: API purity, a11y, composition, styling escape hatches, docs DX, headless honesty.
3. Each persona: `Adopt` | `Adopt with changes` | `Reject` + concrete defects.
4. Record outcomes in the component MD Review log.
5. Findings must stand on technical merit; persona is a lens only.
